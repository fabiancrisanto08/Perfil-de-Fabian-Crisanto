Hola, soy **Fabian** (aunque en casa todos me conocen como **Adriano**). Me apasiona entender cómo funciona la tecnología desde su arquitectura interna y lógica de servidor hasta la interfaz que ve el usuario.

* **Enfoque actual:** Desarrollo web full-stack, creación de APIs CRUD, bases de datos y despliegue de aplicaciones modernas.
* **Meta profesional:** Convertirme en un gran **Ingeniero de Hardware**, combinando ese perfil técnico con mi carrera como desarrollador y programador web.
